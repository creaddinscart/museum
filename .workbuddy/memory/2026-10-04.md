## 工程约定 / 关键坑

- `tools/smoke-test.js` 用的是 `print()` / `load()`，Node 跑不了。
  必须用系统自带 JavaScriptCore：
  `/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc tools/smoke-test.js`
- 数据文件 `assets/js/data-0*.js` 必须先于 `assets/js/app.js` 加载（依赖 `window.MUSEUM_CATEGORIES` 等全局变量）。
- `app.js` 会硬引用全部 DOM id：`app / gate / gateList / gateSearch / ring / ringWrap / listing /
  search / favCount / regionLabel / btnRegion / btnFav / btnRandom / btnReset / footStamp`。
  任一缺失都会让 `boot()`/`render()` 抛错，表现为"按钮全部点不动"。改动 HTML 时务必同步。
- 加密货币展区按地区限制：`CRYPTO_BLOCKED` / `CRYPTO_WARN` 在 `assets/js/data-base.js`。
- `.regression-backup/` 是本次的回退版归档，未跟踪、不会发布；确认后可直接删除。

## 404 页（同日 08:2x）

  相对路径会导致样式和导航全崩。改这个文件时绝对不能改回相对路径。
- 带 `noindex`（opts.noindex），**不进 sitemap**。
- 内容：404 标题 + 回首页/展区列表/完整目录 + 12 个最热展区 + 联系提示。
- 本地验证方式：用模拟 GH Pages 的临时 server（缺失路径一律回 404.html），
  确认深层路径下 title 正确、资源 href 均为 `/` 开头且 200。
