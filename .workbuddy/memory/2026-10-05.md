## 短地址路由 router.js（接 10-04 的工作，凌晨继续）

用户要求："停止使用 .html，换成 /?内容 这个格式，默认后面 = 还可以变成搜索词条"。
追问后用户答复"哪一个方便哪一个来""最好你自己加入所有我们需要的功能"，
于是自行决定方案：**保留静态 .html 做兜底，另加 ?query 路由层**。

### 为什么不全站删掉 .html

GitHub Pages 是纯静态：`/?countries` 实际请求的仍是 `/` → `index.html`，
查询串由浏览器端 JS 解析。若删掉全部 .html，则：
必须开 JS 才能看到任何内容、313 个页面的搜索收录全部归零、无 JS 访客白屏。
所以两层并存：**.html 是权威地址（可收录、可直链），/?xxx 是快捷写法。**

### 关键实现细节

- `page()` 里首页 body 被包进 `<div id="home">`，后面追加 `<div id="view" style="display:none">`；
  router 命中查询串时隐藏 #home、往 #view 里渲染。
- 首页额外加载 `router.js`（在 script.js 之前），其余页面不加载。
- 国家/插头路由**按需动态 `load('countries.js')`**（119 KB）+ `load('plugs.js')`，
  避免首页白背 119 KB；站点和文物走已加载的 `picks.js`。
- 搜索里的国家结果因为要等 countries.js，**异步追加**（`view.innerHTML +=`），
  先出站点/文物结果再补国家，体验上不阻塞。
- **全站每页页脚都加了搜索框**：`<form action="/" method="get">` + `<input name="=">`。
  `name="="` 这个写法会直接产出 `/?=关键词`，正好是用户要的格式；action 用绝对路径 `/`，
  这样从 `countries/france.html` 这种深层页面提交也能回到根。
- 首页之外不引 router.js，所以 `/categories.html?=x` 这种不走路由（符合预期，
  用户要的是根域 `/?=x`）。

### 踩坑

1. **picks.js 里站点字段名是 `u` 不是 `url`** —— router 里写成 `s.url` 会渲染出
   "undefined"。`siteRow()` 必须用 `s.u`。（sites.js 里才叫 `url`。）
2. 用 Node 测 router 时，**国家/插头是两级嵌套 `load()`**，需要 2 个 tick；
   断言延时给 20 ms 会误判成"没渲染"，给 120 ms 才稳。别据此改代码。
3. `countries/congo.html` 是旧 slug 的残留（现为 `republic-of-the-congo`），
   build.js 不会自动清理。判断方法：比对 `countries.js` 的 slug 集合与目录文件名集合，
   差集即陈旧文件。本次 0 引用、不在 sitemap，已移到 `/tmp/museum-stale/` 备份而非直接删。
